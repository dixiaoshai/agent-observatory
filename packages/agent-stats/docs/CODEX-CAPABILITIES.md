# Codex 接入能力与边界

Agent Stats 只读 Codex 本机 rollout JSONL。该格式是版本相关的本地格式，不能当作稳定公开 API。Codex 存在落盘的 rollout，也存在 `codex exec --json` 事件流；本项目读取已有 rollout，不实现 exec 标准输出流采集，二者不能混为一谈。字段支持依据本机样本的元数据结构与项目合成夹具验证，不由官方说明推断。pi 与 dsh 经 Agent Trace metadata 适配，字段与成本口径见[数据源契约](SOURCES.md)。

## 能力声明

| 领域 | 适配策略 | 降级与限制 |
| --- | --- | --- |
| 会话身份 | `session_meta.id`，加 source / instance 命名空间 | 无身份的文件报告采集问题；不同 instance 不合并 |
| 会话名称 | 来源所属 Codex 目录的 `state_*.sqlite` 中 `threads.name`，回退 `session_index.jsonl.thread_name` | 刷新采集同步重命名；无名称时显示未命名或子代理会话并单列原生 ID；不读取 `threads.title` 或 `first_user_message` 生成名称 |
| 轮次 | `turn_context.turn_id` 与任务生命周期 | 无可靠身份时保留推断 / 未归属标记，不伪装成原生轮次 |
| 事件时间 | 源 timestamp 规范化为 UTC；另记采集时间 | 窗口按轮次开始时间，半开区间；页面说明时区 |
| 用量 | `event_msg` 内 `token_count.info.total_token_usage` 累计差分；分叉时扣除可确认的继承基线 | 不把每个累计值相加；不从快照数推算模型请求数；缺失、重置或分叉基线无法确认时保留未知并报告覆盖限制 |
| 分类 | 输入、缓存输入 / 写入、输出、推理输出分别保留 | 样本中总计等于输入加输出，缓存 / 推理数值不超过相应主类；这是观察结果而非公开契约。合计不叠加分类；缓存写入不作计费解释 |
| 缓存统计 | `cached_input_tokens` 与 `input_tokens` 成对聚合，展示缓存读取、未缓存输入及占输入比例 | 只用两者均为非负整数且缓存不大于输入的轮次，附配对覆盖；零输入时比例未知。缓存写入按来源字段单独统计，不混入读取比例 |
| 模型 | 轮次上下文明确提供的模型 | 未知保留未知；会话跨模型时不能用最后模型给全部历史定价 |
| 工具 | `response_item` 调用及结果，以 `call_id` 关联 | 只存名称、身份、字节规模与来源定位；缺少显式成功 / 失败状态时保持未知；不解析命令输出猜测成功 |
| 子任务 | 有明确来源父身份时保留关系；依据本机样本按各会话新增用量合计 | 日志格式和计量行为依版本而异，样本观察不是公开契约；旧记录缺少计量标记时父子同现须刷新采集，否则展示未去重观测小计 |
| 费用 | API 列表价等价估算；来源记录成本（如 pi）优先 | 按 `agent_stats/pricing.py` 的当前公开 API 列表价计算（OpenAI Standard 短上下文；DeepSeek 按请求时间区分 peak / off-peak），展示覆盖与部分小计；记录成本存在时不按当前价目表重算；实际账单未知，未知单价不补零；`codex-auto-review` 在账号范围信号成立且轮次不早于 2026-10-06 时按免费估算为 0，否则保持未知 |
| 请求数 | 不支持 | 消息数、Token 快照数、工具数均不等于模型请求数 |
| 上下文 / 节省量 | 不支持精确测量 | 不能把累计输入当作上下文长度，也不把工具字节换算 Token 或费用 |
| 隐私 | 默认元数据模式 | 保存最多 80 字符的 Prompt 轮次摘要；不保存完整 prompt、思考、命令、参数、结果正文；摘要、路径和身份仍可能敏感 |

## 统计口径

- 同一会话可能有多个 rollout（恢复、子代理等）。采集按（最后事件时间、事件数）选择最新修订，较旧副本不会覆盖较新用量；不能把多份累计快照合并相加。
- 累计快照差分归入对应轮次；重复事件不新增用量。累计值重置后不跨计数周期猜测增量。分叉聊天复制历史，首个快照用可确认的 `last_token_usage` 扣除继承基线；基线缺失、无效或时间无法区分历史时保留未知并提示。
- 父子会话按各会话新增用量合计，不把父会话历史重复计入子会话。父子计量关系无法核实、或旧采集缺少分叉身份时，查询会标记聚合受限，只展示带标注的观测小计，并在页面提示刷新采集。
- `token_total` 只在当前范围全部轮次有有效值时返回完整合计；`token_known` 是有效轮次的已知小计。`observed_token_total` / `observed_token_known` 是未去重的观测值求和，页面会明确标注。缺失始终为 `null`，不补零。
- 分位数使用 Hyndman-Fan type 7 线性插值，只计算有效轮次，并附有效 / 总样本数。
- 缓存占输入 = 同批有效配对轮次的缓存读取总量 / 输入总量，是 Token 比例而非请求命中率；缓存读取已包含在输入中，不重复加入总 Token。
- `token_count` 中 `info: null` 且附有非空 `rate_limits` 的事件只更新限额，不代表缺少用量，不触发累计快照警告；真正无有效累计值的用量记录仍会提醒，并保留文件与行号定位。
- 费用估算在查询时动态计算：普通输入 = 输入 − 缓存输入；公式为普通输入 × 输入价 + 缓存输入 × 缓存价 + 输出 × 输出价，费率按美元 / 百万 Token 换算。推理已包含在输出，不重复计费。未记录缓存写入时假设无单独计费写入；写入为正但缺少 TTL 时无法估算。未知模型或缺少有效分类时保留未知；覆盖不完整时只展示已知小计。当前估算未还原逐请求长上下文、服务等级、工具附加费或历史费率，实际账单字段 `cost` 为 `null`。
- 账号范围信号：`session_meta.creator_account_id` 为非空（去掉首尾空白后）字符串时会话标记 `account_scoped=true`，Trace 归档以 `session.auth` 元数据事件传递同一布尔含义；只保存布尔值，不保存原始账号 ID，同一会话多份 rollout 时只采用被选中修订的证据。该字段也会用于 Codex Agent 身份 / PAT，日志无法区分登录方式；缺失表示未知，不按 API Key 处理。模型 `codex-auto-review` 且信号成立、轮次 `started_at` 不早于 `2026-10-06T00:00:00Z` 时费用按免费规则（0，`cost_basis=free`）估算，其余情况保持未知。
- 轮次名称从该轮可读用户 prompt 或子代理 `NEW_TASK` 的明文 Payload 生成最多 80 字符的单行显示摘要，剔除 AGENTS、环境与开页注入上下文；加密或不可读内容不尝试解密，以“第 N 轮 · 无可读 Prompt”回退。会话 ID 与轮次 ID 不变；刷新采集后历史轮次会更新。
- 工作区名称优先读取来源状态库的项目与会话关联，否则按项目根目录匹配并支持 Git worktree；无可核实项目名时回退目录名。项目原路径保留用于筛选和悬浮查看。

## 数据可靠性

SQLite 保存规范化会话事实，按稳定来源身份替换 / 合并导入；重复采集不追加用量。活动 / 归档副本使用同一 instance 去重。损坏行、无法解析的尾行、来源读取失败必须返回采集警告；未知指标保持未知。日志迟到后再次刷新会重建受影响的事实，查询不缓存旧聚合。读取 Codex 状态库获取名称 / 项目时使用只读连接，保留 WAL 中已提交的重命名；状态库缺失或版本不兼容时回退 JSONL 名称索引或目录名。

## 隐私边界

默认元数据模式：只保存会话显示名、最多 80 字符的 Prompt 轮次摘要、Token 与工具计数、事件定位等统计元数据；不保存完整 prompt、思考、命令、工具参数或结果正文。摘要、名称、项目路径、身份与文件定位仍可能包含工作信息，数据库请按本机敏感数据管理。正文下钻仅在显式配置 Agent Trace content 归档时启用，且不写入统计库。

## 当前限制

- 无法验证精确模型请求数、逐请求费用、完整缓存写入开销与工具错误率；这些是明确缺口，不提供近似替代指标。
- 真实 Codex 宿主的长期运行、版本升级后的字段变化、时区与生命周期异常仍需在实际使用中核对；本模块的合成回归不代表覆盖所有版本。
- 父子与分叉计量依赖本机版本观察到的累计关系，不是所有版本的公开契约；证据矛盾时保留未知。
- 不实现优化比对、预算、自动费率回填、跨设备同步或因果诊断；高消耗不等于浪费。
